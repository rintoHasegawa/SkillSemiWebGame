# testing（テスト専用フィクスチャ）

ユニットテストから共有するフィクスチャ（テストデータ生成関数）を置くディレクトリである．

- **本番コードから import してはならない**．ビルド対象からは `tsconfig.build.json` の `exclude` で除外している．
- テスト本体は対象ファイルと同居させる（`.claude/rules/testing.md`）．本ディレクトリはテスト間で重複していた**データ生成とポート・アダプタのスタブ**のみを集約する．
- 2〜3 メソッドだけを差し替える局所的なスタブは，各テストファイルにローカルで置く（重複ではなく意図的な絞り込みのため）．
- 各ファイルの用途はファイル先頭のドキュメントコメントを参照する．
